# LinguisPlay 用户体验设计稿 v2（调研修订版）

> 2026-07-09。v1 出稿后按 Yi 要求做了对标调研，本版为修订版。
> 对标对象：星野（MiniMax，六大对话控制+星念经济）、恋与深空（叠纸，拍立得/日常互动）、
> 猫箱（字节，语音+主动性+信息流发现）、Character.AI（重说经济）、视觉小说成熟惯例。
> 调研来源见文末。
>
> **核心判断不变：引擎账本已经很富，UX 欠的是把账本变成【看得见的进度】和
> 【拿得住的奖励】。** 调研新增一条：**欠一套「玩家控制权」——重说/回溯/事件簿
> 是这个品类的信任基建，全行业标配，我们完全没有。**

## 设计原则

1. **账本即界面**：UI 上每个数字/进度/提示直接来自引擎账本，不造第二套状态
2. **逼近感优先**：能显示「还差多少」的地方绝不只显示「现在多少」
3. **稀有时刻要有实体**：好瞬间必须凝固成可收藏、可回看、可展示的«东西»（星野星念 = 「记忆相片」双面卡、恋与深空拍立得，两家分别验证）
4. **别让玩家猜玩法**：剧情本和沙盒本从选本那一刻就分清楚
5. **（新）坏回合要有出口**：模型会出烂活，玩家的出口不能是骂客服——是重说和回溯（星野六件套的头两件；Character.AI 甚至把重说次数做成了付费点）

---

## 第零层 ·（新增）玩家控制权：对话控制件套（P1，信任基建）

**调研依据**：星野六大机制（重说/回溯/记忆/重启/评价/事件簿）被分析文章认定为
「消解大模型幻觉、让进程最大化由用户控制」的成功关键；SillyTavern/Character.AI
的 swipe 是品类第一交互。**我们一件都没有**——Yi 遇到烂回合只能截图给开发者。

| 机制 | 设计 | 引擎成本 |
|---|---|---|
| **重说** | 最新一回合右下角 ↻，重新演这一拍（保留玩家输入，重掷计划+渲染）；左右滑在多个版本间选 | 中：需回合前状态快照（state 已整存整取，快照一份即可）；beats 按 seq 截断重写 |
| **回溯** | 长按任意历史拍 →「回到这里重新开始」 | 中：同上，按 seq 存档点 |
| **事件簿** | 把引擎的记忆摘要（memory_by_char 已有）直接开给玩家看：「TA 记得的你们」 | 低：纯呈现 |
| **文字速度/自动/跳过** | VN 标配三件：打字速度挡位、自动播放、点击跳过打字直出全文 | 低：纯前端 |
| **评价** | 对一拍点 👍/👎，喂给守卫开枪榜同一条管线做数据 | 低：埋点 |

重说排 P1 之首：它同时是体验修复口、数据回收口（哪类拍被重说=哪里烂）、
和将来的付费点（Character.AI 已验证每日重说上限收费）。

## 第一层 · 门面与导航（P0，Yi 亲身踩坑）

- 剧本卡分型：📖 剧情本（N幕·主线·预计时长·结局数）vs 🏖 沙盒本（无尽·成长阶梯名）
- 开局玩法卡（3 秒可跳过）：这个本要做什么、什么会涨、去哪看进度
- **（新）发现流**：猫箱用抖音式上滑刷角色做发现，次日留存全品类第一——我们本子少
  暂不需要，但**开场白即演出**值得抄：本子卡点开先播开场钩子的前两行，再让玩家决定进不进
- 数据源全有（sandbox/acts/progression），纯前端

## 第二层 · 进度可视化（P0，设计文档自己的 🥇）

- **追求条**（顶栏常驻）：剧情本 `第2幕·立足 ▸ 碎片1/2 ▸ 与十二少交情 5/8`；
  沙盒本显示自己立的追求（钉住的找人/约定/修为下一档）
- **关系逼近感**：头像下微型双轴条（好感/心动），距下一档 ≤3 点亮「差一点」微光
  （`再近一步，他就不当你是外人了`）
- 回合末 rel_deltas 飘字补第二行「离下一档还差X」（仅 ≤3 时）
- 数据源：act_progress / relationships.state_for（next tier 已算好）

## 第三层 · 回合内体验（P1）

- **骰子三色演出**：绿成/黄险成/红败，险成骰面落定抖一下、代价小字跟随
- **心象仪**：长按气泡浮出「TA此刻：强装镇定」（self_state 已在流里）
- **建议 chips 分型**：第 1 条「顺着你」主色加重，2/3 条浅色
- **流式输入态**：流式时输入框显示「▌正在演这一拍…」+ 跳过打字按钮
- **（新）按住上滑看背景**（星野细节）：上滑暂隐文字露出场景背景图，松手回来

## 第四层 · 奖励时刻：时刻卡回忆册（P2，留存与商业化地基）

**调研强化**：星念卡 = 双面「记忆相片」（正面角色/场景图，背面你们的故事线），
获取三渠道（聊天掉落/许愿池抽取/交易市场），每日免费一抽；恋与深空拍立得大头贴
同构。这是两家已验证的核心留存+付费循环，我们的差异化是**卡面内容由真实剧情时刻生成**，
不是预制卡池。

- 触发：golden moment / 秘密拼全 / 关系跳档 / 大成功骰 / 结局里程碑 / 修为突破
- 形态：双面卡——正面：场景背景图 + 关键一句；背面：那一拍前后的故事摘录 + 日期 + 稀有度
- 入口：侧栏「回忆册」网格，空位剪影勾收集欲；卡可设为聊天背景（星野验证的高频用法）
- 远期挂载：每日免费开卡 → 许愿池 → 交易（星野全链已验证，此处只留接口不做）
- 数据源：moments 事件全在流里 + enrich 背景图管线

## 第五层 · 离场与回归（P3，留存闭环）

- 悬念离场卡（parting hook 已生成）：「TA还有话没说完」+ 约定时间，回归首屏展示
- 回归摘要卡：「你不在的这段日子」三行（world_news/offscreen 离线期已生成）
- 约定面板 + 到点 phone 提醒（promises_view/phone 通道已有）
- 修为离线温养飘字（cult 已支持）
- **（新）角色主动性**：猫箱的高拟人=「角色会主动发起话题」——我们 phone/offscreen
  通道已有，设计成：离开 N 小时后角色按人设主动来一条消息（想你了/有线索了/催约定），
  频控每日 ≤1，可关

## 落地顺序（v2 修订）

| 批次 | 内容 | 理由 |
|---|---|---|
| **P0** | 选本分型+玩法卡+追求条+关系逼近感 | 纯前端接现有账本；治「不知道在玩什么」 |
| **P1** | **重说+回溯**（控制权头两件）+ 骰子三色 + 心象仪 + 建议分型 + VN三件（速度/自动/跳过） | 重说是信任基建+数据回收口，调研后从缺席提到最高优 |
| **P2** | 时刻卡回忆册（双面卡+网格+设背景） | 留存地基，值得单独一刀 |
| **P3** | 离场卡+回归摘要+约定提醒+角色主动消息 | 数据源全在，纯呈现+频控 |
