# LinguisPlay 用户体验设计稿 v1

> 2026-07-09。前置：plan/render 流式已全量、骰子险成档、找人合同、行协议渲染均已上线。
> 本稿只做设计不做实现，供拍板后排期。
>
> **核心判断：引擎账本已经很富（关系轴/修为/约定/碎片/离场钩子/世界新闻/大事记全在记），
> UX 欠的不是新系统，是把账本变成【看得见的进度】和【拿得住的奖励】。**
> 依据：gameplay-design.md 的三层循环 + 318 回合数据 + Yi 实玩踩坑 + 星野/Hidden Door 对标。

## 设计原则

1. **账本即界面**：UI 上出现的每个数字/进度/提示都直接来自引擎账本，不造第二套状态
2. **逼近感优先**：能显示「还差多少」的地方绝不只显示「现在多少」（完成欲 > 现状陈述）
3. **稀有时刻要有实体**：好瞬间必须凝固成可收藏、可回看、可展示的«东西»，不能流过就没
4. **别让玩家猜玩法**：剧情本和沙盒本是两种游戏，从选本那一刻就说清楚

---

## 第一层 · 门面与导航（P0，Yi 亲身踩坑）

**问题**：浮生（纯沙盒）和龙头（四幕正剧）在选本页长得一样，Yi 玩错本追了 20 回合
不存在的人；游戏从头到尾没告诉他这是个什么玩法的本。

**设计**：
- 剧本卡分两类，视觉即区分：
  - 📖 **剧情本**：角标「N幕·主线」，卡上一句钩子 + 预计时长 + 结局数
  - 🏖 **沙盒本**：角标「无尽·世界随你生长」，卡上显示成长阶梯名（如「街坊声望：生面人→城寨王」）
- 开局第一拍前插一张「玩法卡」（一次性，3 秒可跳过）：这个本你要做什么、什么会涨、去哪看进度
- 数据源：`story.sandbox.enabled`、`acts`、`sandbox.progression`（全都有，纯前端工作）

```
┌──────────────────┐  ┌──────────────────┐
│ 九龙城寨·龙头     │  │ 九龙城寨·浮生     │
│ 📖 四幕·主线      │  │ 🏖 无尽沙盒       │
│ 卧底刑警蔡妍……    │  │ 街坊声望：        │
│ ⏱ 3~5小时 ★2结局 │  │ 生面人→→→城寨王  │
└──────────────────┘  └──────────────────┘
```

## 第二层 · 进度可视化（P0，设计文档自己的 🥇）

**问题**：好感/心动/碎片/幕门槛全在暗处走，玩家体感=纯闲聊（318 回合数据 + Yi 反馈）。

**设计**：
- **追求条**（顶栏常驻，替换现在的 goal 一行字）：
  - 剧情本：`第2幕·立足 ▸ 碎片 1/2 ▸ 与十二少交情 5/8`（数据源：`act_progress` 已有）
  - 沙盒本：自己立的追求：最近钉住的找人/约定/修为下一档（`char_pins`/`promises`/`cult_view`）
- **关系逼近感**：角色头像下加微型双轴条（好感/心动）；距下一档 ≤3 时点亮
  「差一点」微光 + 文案（`再近一步，他就不当你是外人了`）。数据源：`relationships.state_for`
  已算 next tier。
- **回合末飘字升级**：rel_deltas 已在飘，补「离下一档还差X」的第二行（只在 ≤3 时）

## 第三层 · 回合内体验（P1，流式刚上线的收尾）

- **骰子演出补险成档**：三色（绿=成/黄=险成/红=败），险成的骰面落定时抖一下，
  代价文案用小字跟在结果后（`成了，但惊动了人`）——把 fail-forward 的设计感传给玩家
- **心象仪**：`self_state`（角色真实内心）已随台词返回，`mind_reader` 开关已有——
  设计为长按气泡浮出「TA此刻：强装镇定」，默认开（这是 EQ 系统的可见化，白拿）
- **建议 chips 分型**：第1条永远是「顺着你」（引擎已保证），视觉上给它主色调加重；
  2/3 条浅色。玩家一眼知道哪个是「继续干我正在干的事」
- **流式期间输入框状态**：流式时显示「▌正在演这一拍…」+ 可打断按钮（打断=跳过打字直接出全文，
  不是取消回合）

## 第四层 · 奖励时刻（P1-P2，对标星野的收集经济，装我们的芯）

**问题**：318 回合 golden moment 只掉 3 次、heat 升档 7 次——高潮太稀，且流过就没了。

**设计**：**时刻卡（回忆册）**
- 触发：golden moment / 秘密整条拼完 / 关系跳档 / 大成功骰 / 结局里程碑 / 修为突破
- 形态：一张卡 = 那一拍的关键文字 + 场景背景图 + 角色名 + 日期 + 稀有度框
  （普通/稀有/传说，按触发类型定）
- 入口：侧栏「回忆册」，网格陈列；空格子显示剪影 + 「？」（收集欲）
- 分享：导出为图（后期）；交易（远期，星野模式）
- 数据源：`moments` 事件已全在流里，背景图已有 enrich 管线——主要是前端 + 一张卡模板

```
┌─────────────────────┐
│ ✨ 传说时刻          │
│ [场景背景图]         │
│ 「进了城寨门，       │
│   就是自己人。」     │
│  龙卷风 · 第3天夜    │
└─────────────────────┘
```

## 第五层 · 离场与回归（P2，留存闭环）

- **悬念离场卡**：parting hook 已生成——离场时凝成一张「未完」卡：钩子文案 + 
  「TA还有话没说完」+ 下次约定时间（若有 promise）。放在回归时首屏
- **回归摘要**：`world_news`/`offscreen` 已在离线期生成——回归第一拍前给「你不在的这段日子」
  三行摘要卡，然后角色的回归问候接上（returning=True 已有）
- **约定面板**：promises_view 已有——侧栏「约定」列表 + 到点用 phone 通道来消息提醒（已有通道）
- **离线温养**：修为的离线增长（cult 已支持）回归时飘字：`离开的两天，气海温养 +4%`

## 不在本稿

移动端适配（等前端路线拍板：static html 继续 vs 激活 apps/web）、付费墙、成就系统扩展、
背景图自动生成（涌现地点还是渐变兜底）。

## 落地顺序建议

| 批次 | 内容 | 为什么先做 |
|---|---|---|
| **P0** | 选本分型卡 + 玩法卡 + 追求条 + 关系逼近感 | 全是纯前端接现有账本；直接治「不知道自己在玩什么」 |
| **P1** | 骰子三色演出 + 心象仪 + 建议分型 + 流式输入态 | 回合内手感，代码量小 |
| **P2** | 时刻卡回忆册 | 留存核心，工作量最大，值得单独一刀 |
| **P3** | 离场卡 + 回归摘要 + 约定面板 | 数据源全在，纯呈现 |
