# LinguisPlay 引擎运行逻辑

> 一句话：**内容由 AI 生成，规则由引擎立法**。模型是演员和导演，引擎是物理规则、账本和裁判。
> 任何"世界状态"的改变，要么由引擎确定性地执行，要么由模型申报、引擎校验后落账——绝不存在"模型说了就算"。

## 0. 三条铁律（所有系统的母规则）

1. **确定性孪生**：凡是玩家意图明确的操作（搜证、收纳、取回、受赠、移动、找人），引擎自己解析执行，不等模型判定。模型判定字段只是这些操作的"备份通道"。
2. **Depth-0 锚定**：模型爱漂移的事实（输出语言、在场人数、当前地点、当前时间、说/做/想通道、成人模式）必须在**生成点旁边**重述一遍——system prompt 里的指令压不住 14 条历史之后的生成。
3. **申报-校验-落账**：模型申报的每个事件先过校验（持有权/在场/余额/规则），通过才改状态；通过与驳回（含原因）都进本回合的**审计单**（`state.last_audit`，SSE `audit` 事件，前端 console 可见）。

## 1. 回合管线（run_turn_stream 的执行顺序）

| 阶段 | 做什么 | 关键函数 |
|---|---|---|
| 0 归一 | 补全 state 默认键；地点归一到有效值 | `default_state` `current_location` |
| 0' 时钟 | 真实同步局把墙钟镜像进 `state.clock` | `sync_real_clock` |
| 1a 解锁 | 关键词试探计数、事件触发、五条件解锁评估 | `gating.evaluate_unlocks` |
| 1b 孪生 | **审计单清零** → 说走就走（含多跳寻路）→ 找人弹窗（可短路本回合）→ 搜证 → 取回 → 收纳 → 受赠 | `player_move` `player_seek` `search_props` `retrieve_stash` `stash_items` `accept_item` |
| 1c 命运 | 「做」通道有风险的动作：模型评险、引擎掷 d20，结果强制入戏（确定性移动回合免掷） | `_roll_check` |
| 2 选角 | 谁接话（primary）+ 群戏成员由 primary 的 next_speakers 决定 | `pick_responder` |
| 3 导演 | 每位发言者一次生成：门控上下文（只喂 TA 有权知道的）+ 关系手艺块 + 声线范例 + depth-0 锚点 | `qwen.generate` |
| 3' 守卫 | 逻辑校验（缺席者闯入/泄密）→ 带错重写一次 → 消毒；英文局中文漂移同回路重写 | `_logic_guard` `_lang_guard` |
| 4 落账 | 模型申报的事件逐个校验落账（见 §3 事件表），全部进审计单 | （runs 循环内 + `_audit`） |
| 5 世界 | 回合数推时段（真实局不推）；时段翻转 → 作息换位、幕后戏、进出场旁白 | `offscreen_drama` `entrance_beat` |
| 6 final | 状态/场景/在场/进度/建议/审计随 final 下发 | `_finish_audit` |

## 2. 系统清单（引擎拥有的状态与不变量）

| 系统 | state 键 | 不变量 |
|---|---|---|
| 门控解锁 | `unlocked_fragment_ids` `asks` `triggered_event_ids` | 五条件 AND；解锁粘滞不回滚；未解锁内容永不进提示词 |
| 关系 | `rel[cid]{closeness,romance}` | 每回合步进有夹钳、收益递减；档位由分数+作者白名单推导，不能跳档 |
| 时钟 | `clock{day,slot,turns_in_slot}` `real_epoch` | 真实局 slot=墙钟(晨05-11/午12-17/夜18-04)；约定=真实日子 |
| 在场 | 角色作息+`char_sim[cid].pos`+`following`+`char_pins` | 位置解析顺序：跟随 > 濒死倒地 > **约见钉** > 作息 > 记账位置 > 开局地 |
| 地图 | `location_id` `stashes` `place_facts` | 移动必须走已解锁出口（可多跳）；场面事实只增不撤（砸开的门不复原） |
| 物品 | `inventory` | 四孪生 + 判定字段双通道；无中生有一律驳回（造物需材料在手，受赠需世界里真有） |
| 金钱 | `money` `money_log` | 硬账本：花钱截到 0；每笔有缘由和时刻 |
| 生命 | `player_hp` `char_sim[cid].hp` `dead_character_ids` | 两段式：健康之身先判濒死，永远留施救窗口；死者永不再登场 |
| 压力 | `pressure` | 0~100 夹钳；越级播报按作者配的档位文案 |
| 幕 | `act` `turns_in_act` | 硬门控幕不集齐钥匙不开；抉择卡答案落 `choices` |
| 议程 | `char_sim[cid].agenda{goal,step,at}` | 每个角色有引擎持有的"想办成的事"；幕后戏顺着议程推进而非随机 |
| 审计 | `last_audit` | 每回合清零重记；驳回必带原因 |

## 3. 事件表（模型申报 → 引擎校验）

| 申报字段 | 校验 | 驳回时审计原因 |
|---|---|---|
| `item_gained` | 未持有才入包 | 已在身上，不重复入包 |
| `item_lost` | 必须在包里 | 身上没有，不能凭空失去 |
| `item_stashed` | 在包里 + 有当前地点 | 身上没有这件东西 |
| `crafted 名|材料` | 材料全部在包 + 判定未失败 | 材料不齐 / 命运判定失败 |
| `taken 物|人` | 受害者在场 + TA 真持有 + 判定未失败 | 不在场 / 身上没有 / 没抢到 |
| `trade 出|进` | 双方各自真持有 | 你没有筹码 / 对方拿不出 |
| `gift 物|反应` | 玩家真持有；收/拒由角色演 | 你身上没有，送不出去 |
| `money_delta ±n|缘由` | 经济开启 + 余额截断 | 没有入账 |
| `harmed 人|程度` | 受害者在场且在世 | 伤的人不在场景里 |
| `character_died 人` | 在场 + **必须已濒死** | 不在场 / 两段式先判濒死 |
| `player_harm` | 沙盒 + 未死；两段式同上 | — |
| `npc_moves [{who,to}]` | 在场 + 不被作息钉住 + 目的地存在 | 不在场/被作息钉住/目的地不存在 |
| `new_character 名|简介` | 未到上限 + 不同名 | 上限已到 / 同名不重复登场 |
| `move_invite 地点` | 只能"提议"，玩家确认后才移动 | （永不静默瞬移） |
| `world_fact` | 去重后记入该地的场面事实账本 | — |
| `promise` | 落成真实日期的约定 | — |
| `probed/occurred` | 与关键词试探对账（解锁粘滞） | — |

## 4. 引擎管什么 / 模型管什么

**引擎（法律）**：谁在场、在哪、几点、谁死谁活、包里有什么、钱剩多少、什么解锁了、关系几档、
幕开没开、约定到没到期、移动能不能走、事件成不成立。

**模型（表演）**：怎么说话、怎么演、气氛与文笔、角色的意愿与情绪、对模糊输入的解读、
以及对上述事件的**申报**（引擎复核）。

**玩家（意志）**：明确的操作走确定性孪生秒执行；模糊的表达交给模型演绎；
所有"世界替你做的决定"（带去、找人）都要玩家点头。

## 5. 调试

- 浏览器 devtools console：每回合一组 `📋 engine audit`，✓=采纳 ✗=驳回（含原因）。
- 服务端：`state.last_audit` 持久在 run 状态里，可直接查库复盘上一回合。
- `lint_stories.py`：剧本结构体检 + 全库跨剧本 id 撞名守卫（美术命名空间）。
- 232+ pytest：每条引擎法律都有回归测试；mock LLM 保证确定性。
