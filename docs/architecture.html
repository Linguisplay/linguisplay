一、三权分立 —— 引擎的宪法

🧍 玩家 · 意志

  • 明确操作秒执行：去哪/找人/搜证/收纳/受赠 走确定性孪生，不等模型赏脸
  • 模糊表达交给演绎：情绪、试探、闲聊由模型接
  • 世界替你做的决定要你点头：带去/找人确认框
  • 金手指是更高法则：声明过的能力无条件生效、免掷骰

⚙️ 引擎 · 法律

  • 事实归引擎：谁在场/在哪/几点/谁死谁活/包里有啥/钱剩多少/什么解锁了
  • 申报-校验-落账：模型报的每个事件先验（持有权/在场/余额）再入账
  • 驳回必留痕：每回合审计单，✗ 带原因
  • 推拉有排程：暖场峰值→下次见面回撤，欲擒故纵是规则

🎭 模型 · 表演

  • 怎么说怎么演：文笔、气氛、角色意愿与情绪
  • 有界裁量：行动难度只能调一档；解锁与死亡无权拍板
  • 被三检盯着：缺席闯入/泄密/中文漂移/压制金手指 → 强制重写
  • Depth-0 锚定：语言/人数/地点/时间/通道/指涉钉在生成点旁

三、回合管线 P0-P9（run_turn_stream）

P0
归一与时钟

state 默认键补全 · 地点归一 · 真实时钟同步（沙盒=墙钟）· 亡者只可旁观

P1
感知

关键词试探计数、事件触发（暂记，P7 由主角判定对账）

P2
确定性孪生

审计单清零 → 说走就走（多跳寻路）→ 找人（弹确认+钉人，可短路整回合）→ 搜证 → 取回 → 收纳 → 受赠

P3
行动解算

动词类目→基础难度→模型调档（±1）→伤势/道具修正→DC→d20；金手指按名动用免掷

P4
解锁与问候

五条件门控评估 · 阈值时刻 · 回归者的 offline pulse（短信/来电/信）

P5
选角与脚手架

responder 路由 · 赴约识别 · 身份演化 · 卡关梯度 · 🧩指涉摘要 · emit()

P6
确定性旁白

孪生的叙事落地（动身/取回/收纳/到手/翻查）——先于任何角色开口 _emit_twin_beats

P7
导演循环

逐人：门控上下文（只喂TA有权知道的）+ 声线范例 + 议程 + 防御风格 + depth-0 锚点 → 生成 → 三检守卫 → _settle_directed 落账（463行校验瀑布）→ next_speakers 扩列

P8
场后结算

金色瞬间掷点 · 观察/心声 · 世界自转 · 好感夹钳递减 → 硬门控推幕

P9
世界翻页

新去处播报 · 时段翻转（作息换位/幕后戏推议程）· 进出场旁白 · 爽约结账 · 手机送达 · 结局评估 · 记忆压缩 · final 装配

四、六大确定性系统

🔐 门控 RAG（内容安全）

  • 碎片解锁 = 好感∧幕∧追问∧事件∧地点 五条件 AND
  • 未解锁内容永不进提示词；cover 谎言统一口径
  • known_by 过滤：谁知道什么，各自为营
  • 指认结案 · 证据对峙（对抗掷点）

💞 关系引擎（留存核心）

  • 亲近/心动双轨，步进夹钳+收益递减，慢建快崩
  • 档位推导（陌生→朋友→暧昧→恋人），作者白名单约束
  • 💘防御风格：傲娇/冷感/回避/占有/直球 + 引擎排程回撤
  • 约定=真实日子；爽约有代价；升恋人寄情书

🕐 时空与人（世界感）

  • 三时段时钟；沙盒与真实墙钟同步
  • 作息表定位 + 约见钉 + 跟随；地图 BFS 寻路
  • 🎯议程：每人一件想办成的事，幕后戏顺着推
  • 龙套层级：无名之辈活跃场景，聊上劲可转正

🎒 物品与经济（硬账本）

  • 四孪生：搜证取物/收纳/取回/受赠，凭空造物一律驳回
  • 制作要材料、抢夺要在场、交易要双方持有
  • 金钱硬账本（花钱截到0）· 差事真截止日
  • 场面事实：砸开的门永远碎着

🎲 行动解算（张力）

  • 10 类可掷动作，命中必掷——模型无免掷否决权
  • easy5/normal10/hard15/extreme19 + 状态修正
  • 自然20/1 恒大成大败；失败强制入戏
  • ✨金手指=更高法则：免掷、满效果、压制即违规重写

📋 守卫与观测（可信）

  • 三检重写：缺席闯入/泄密 · 英文局中文 · 金手指被压
  • 审计单：采纳自 moments 派生，驳回带原因
  • metrics.jsonl：每调用/每回合一行，report 出分位
  • lint_stories：结构体检 + 跨剧本美术撞名守卫

五、一次回合的旅程

玩家输入→ 🧩 指涉核实→ 🚶 孪生执行→ 🎲 难度→掷骰→ 🔐 门控上下文→ 🎭 逐人生成（流式）→ 🛡 三检重写→ 📋 校验落账→ 🌆 世界翻页→ 📦 final

SSE 事件序：dice beat×N clock phone state scene cast here moments goal progress hint place promises verdict choice move_request audit suggest ending done —— 首个角色 2-3 秒开口，其余逐个到场。
