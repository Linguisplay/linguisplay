# 《九龙城寨·龙头》功能流程示意图

> 当前引擎 + 剧本的实际机制。Mermaid 图,GitHub/VSCode(Markdown Preview Mermaid)可直接渲染。

## 1. 单回合引擎流程(玩家每说一句发生什么)

```mermaid
flowchart TD
  IN["玩家输入(说 / 做 / 想)"] --> ASK["检测提问 _detect_asks<br/>匹配秘密关键词 → asks 计数"]
  ASK --> UNLOCK["评估解锁<br/>好感 / 幕 / 提问次数 达标 → 解锁秘密碎片"]
  UNLOCK --> WHO["选出在场发言者<br/>按当前地点过滤(scene_characters)"]
  WHO --> GEN["逐个角色生成<br/>门控上下文 + 关系剧本 + 情商<br/>函数调用: 旁白 / 台词 分离字段"]
  GEN --> ECHO["复读拦截<br/>群戏里 member 不重复别人的话"]
  ECHO --> DELTA["结算好感 / 心动<br/>每个角色各自更新关系分"]
  DELTA --> TIER{"关系升档?"}
  TIER -->|"是"| CELE["💗 升档庆祝演出(陌生→朋友→暧昧→恋人)"]
  TIER -->|"否"| ADV
  CELE --> ADV{"满足推进硬门?<br/>必需碎片 + 好感门槛"}
  ADV -->|"是"| NEXT["进入下一幕 + 转场旁白"]
  ADV -->|"否"| LOC
  NEXT --> LOC{"有新解锁的地点?"}
  LOC -->|"是"| NOTE["(你打听到城寨里还有去处…)通知"]
  LOC -->|"否"| ENDC
  NOTE --> ENDC{"达成结局里程碑?"}
  ENDC -->|"是"| SHOW["结局演出(死亡=终局;其余=里程碑,可继续)"]
  ENDC -->|"否"| SUG
  SHOW --> SUG["生成 3 条情境相关的下一步建议"]
  SUG --> OUT["更新状态 / 背景图 / UI"]
```

## 3. 地点解锁 + 人物分布(探索→相遇)

```mermaid
flowchart TD
  START(["开局落脚"]) --> ALLEY["城寨暗巷 · 蓝信一"]
  ALLEY -. "问出龙卷风开理发店" .-> BARBER["龙卷风的理发店 · 龙卷风 + 十二少"]
  ALLEY -. "同上(fr_whoruns2)" .-> DAI["大牌档 · 四仔"]
  ALLEY -. "第3幕外敌上门" .-> MOUTH["巷口 · 王九(3幕) / 大老板(4幕)"]
  ALLEY -. "挖到龙头深层秘密" .-> ROOF["天台 · 终局俯瞰"]
  BARBER <--> ALLEY
  DAI <--> ALLEY
  MOUTH <--> ALLEY
  ROOF <--> ALLEY
```

规则:角色钉在各自地盘,玩家走到哪才遇到那里的人;**关系够近**才能「邀同行」把人带走;地点要**有人亲口说出地名**才解锁。

## 5. 秘密分层解锁(gated-RAG:门控后才进 prompt)

```mermaid
flowchart LR
  Q["玩家追问某话题"] --> DET["命中该秘密关键词 → asks++"]
  DET --> COND{"好感 / 幕 / asks 达标?"}
  COND -->|"否"| HIDE["角色回避 / 岔开(内容绝不进 prompt)"]
  COND -->|"是"| REVEAL["碎片进入该角色 new_reveal<br/>→ 强制其亲口说出(不许再回避)"]
  REVEAL --> LAYER["同一真相分多层,下一层要更高门槛<br/>(例:谁是话事人 → 龙卷风是谁 → 他的龙头门路)"]
```

八大秘密 / 14 碎片,层层递进,越接近真相门槛越高;真结局要挖到最深两层(城寨的龙头 + 他早看穿了你)。
