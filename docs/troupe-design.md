# 剧组重建（导演/编剧/演员）· 调研与设计

> 2026-07-13 立项。Yi 的诉求：逻辑系统重建 — 要有导演把所有角色卡（含玩家）串联起来，
> 要有编剧；角色卡要有性别（注重多样性）、性格、各自的人生当前目标。
> 本文档先回答「现在到底是什么样、细节问题烂在哪」，再给依病灶开药的重建方案。

## 一、现状地图（调研结论：地基比想象的好，散装比想象的散）

回合管线 P0-P9（runtime.run_turn_stream:6098）与三条铁律（确定性孪生 / depth-0 锚定 /
申报-校验-落账，docs/engine-logic.md）**全部保留**，它们是引擎的法律层，没病。

已经存在的「剧组雏形」——重建不是从零造，是把这些胚胎接骨：

| 剧组职位 | 现有胚胎 | 差距 |
|---|---|---|
| 导演 | pick_responder（选角，五档关键词优先级 :1565）+ director.py（视听演出+审稿） | 没有戏剧判断：不懂冲突、不管钩子、不排群戏 |
| 编剧 | plan 拍（plan/render 双拍，docs/plan-render.md） | 只管主答者单人；没有场次概念；不产 NPC 互戏 |
| 演员 | P7 逐说话者生成（40+ 键 prompt :7117-7209）+ 角色宪章 + 防御风格 | 键在平铺膨胀，卡上没有性别/年龄/性格轴 |
| 角色的人生 | char_sim.agenda{goal,step,at}（:1066，wants 种入）+ offscreen_drama（:3069）+ living 心跳 | goal 种入后永不进化，offscreen 只写 step；「当前目标」是死的 |
| 玩家档案 | profile.py facts/by_char + attrs 五维（:490）+ powers + persona | 四处散落，没有一张「玩家角色卡」给导演读 |
| 人物网 | ties → npc_rel（stance -2..2 + log）+ npc_stances 注入 | 只有幕后戏会动它；玩家在场时 NPC 之间零互动 |

## 二、病灶清单（细节问题的根，全部带坐标）

1. **goal 单槽四写手，无主权规则**。写入点：开场由头 :1870、幕推进 :5491/:6374、
   回合末 :7965（无条件 `goal_for()` 盖写）。后果实锤：开场「捎叉烧」由头活一回合就被
   幕目标顶掉。根因：幕目标/差事/玩家自立目标挤一个槽。
2. **建议有七个产地**（:1871 开场、:2213 smart、:2264 凑三、:2285 build、:2446 到站、
   :4950 自由日、:8060 final 落账），各产地的文风/口吻规则各自为政 —— 粤语漏洞就是
   其中一个产地漏了文风注入，修一处不等于修全部。
3. **wants/agenda 双源，目标不进化**。wants（作者静态）→ 种入 agenda.goal 后永不变；
   offscreen/心跳只更新 step。Yi 要的「人生**当前**目标」在数据结构上不存在。
4. **角色卡没有性别/年龄**。称呼与代词（他/她、哥/姐）靠模型从名字猜；生成班底时
   没有任何多样性守卫（性别混合、年龄跨度、位型分布）。
5. **选角不是导演**。pick_responder 是关键词优先级；群戏名单由主答者自己点
   （next_speakers :7346）—— 演员自己排班，没有第三只眼。
6. **演员 prompt 平铺膨胀**。每加一个系统加一键（已 40+），所有戏剧责任压在单次
   生成上；plan 拍开始收拢但只覆盖主答者。
7. **场景 mood 两套推导**。scene.py 关键词分类器猜 mood/bg，导演 pick_bgm 再消费 ——
   编剧层本可直接申报本场情绪，猜是历史遗留。
8. **NPC 互戏只在幕后**。offscreen_drama 只发生在玩家不在的地点；玩家在场时
   所有戏围着玩家转，群像感假。
9. **伏笔无账本**。stall 欠账只管「卡拍」；开场 tease、编剧埋的钩子没有
   setup/payoff 台账，说了可以不算。
10. **玩家不是一张卡**（见上表末行）。导演要「把玩家串联进来」，先得有东西可读。

## 三、重建方案（依病灶开药，不推倒管线）

在 P5（选角）与 P7（生成）之间插入**导演层**；plan 拍升级为**编剧拍**；
演员层只换卡不换法。守卫/账本/审计原样。

### 1. 角色卡 v2（治 3/4/10）
```
gender: 男|女|其他        # 称呼/代词从卡上走，不再猜
age_band: 少年|青年|中年|老年
traits: {外向 1-5, 温度 1-5, 主导 1-5}   # 给导演排冲突用的三轴，散文人设保留
fear: 软肋一句              line: 底线一句（一推就破的角色不可信）
life_goal: {text, stage, obstacle, log[]}   # 活的目标台账，替代静态 wants 语义
```
玩家同构成卡：persona + attrs + powers + profile.facts + 自报人生目标 归拢为
`player_card`，导演读它和读 NPC 卡同一姿势。
多样性守卫进 lint_stories + 生成合同：班底性别必须混合、年龄有跨度、
位型有分布（恋爱位之外必须有兄弟/长辈/对手位）。

### 2. 目标栈（治 1）
`state.goals = [{kind: act|errand|self, text, from, status}]`。UI 目标条读栈顶；
开场由头压 errand 层、幕推进只动 act 层、玩家自立目标进 self 层；
:7965 的无条件盖写删除。完成/放弃都留痕（审计可见）。

### 3. 导演场次单（治 5/7/8）
每「场」（地点×时段×在场名单变更时）一次调用，结果缓存：
```
scene_brief = {戏眼: 本场最值得发生的一件事,
               心事: {cid: TA此刻最挂心的一步（读 life_goal.stage + 冲突矩阵）},
               主动权: 谁该先开口/谁想找玩家说事,
               钩子: 埋哪个/收哪个（读伏笔账本）,
               互戏: 可选的一对 NPC 本场有自己的交流}
```
冲突矩阵 = ties × life_goal 的确定性交叉（阿娣的债 × 细辉的名单这类），引擎算，
导演挑。pick_responder 降级为无场次单时的兜底。

### 4. 编剧拍（治 6/7/9）
plan 拍升级：输入加 scene_brief，输出分镜含 NPC 互戏拍与 mood 申报
（关键词分类器降级为兜底）；顺手产本回合建议（三条，文风注入一次到位）。

### 5. 建议归一（治 2）
七个产地收敛为「编剧拍产 + ensure_three 兜底」两个；所有产地共用同一段
文风/口吻注入函数。

### 6. 伏笔账本（治 9）
`state.setups = [{text, day, due_day, paid}]`：编剧埋钩必落账，到期未收
提醒编剧收线或明书作废；审计单可见。

## 四、建造顺序

- **P0 卡与栈**：角色卡 v2 字段 + 玩家卡归拢 + 目标栈 + 建议归一 + 多样性 lint
  （病灶 1/2/3/4/10 —— 细节问题最密集的一批，全是确定性改动，风险低）
- **P1 导演**：冲突矩阵 + 场次单 + 选角接管（5/7/8）
- **P2 编剧**：plan 拍升级 + NPC 互戏 + 伏笔账本（6/9）

每步照旧：pytest + smoke 全绿才部署；浮生做试点剧本；灰度旗照 plan_render 前例。
