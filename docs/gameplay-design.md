# LinguisPlay 核心玩法设计 · 方案A:羁绊驱动的剧情解锁

> 用 game-designer 方法(MDA + 自我决定论SDT)产出。这是后续开发的纲。

## 一句话
**关系是主货币。** 日常短聊把它养上去,过阈值就解锁剧情/秘密/恋爱/抉择;没有硬结局,
故事是随羁绊加深而不断展开的一口井。短会话累积成一段越来越深的长期关系。

## 设计支柱(北极星 — 每条机制都要服务它)
1. **被记住、被读懂、被在乎** — SDT·relatedness
2. **关系是你亲手养的,且看得见在涨** — SDT·competence + 可视进度
3. **你说的话真的改变走向** — SDT·autonomy + 后果

## 为什么是 A(而非季播/群像)
玩家要"碎片陪伴 + 长期养成"(留存 1+4),且四种体验全要。纯陪伴留不住、纯剧情会结束。
唯一解:让关系本身成为进度货币,把陪伴/悬疑/恋爱/抉择分层挂在同一个关系循环上,互不打架。

## 三层循环

### ① 每句循环(秒级)
说一句 → 角色用 EQ/独特声音接住 → 好感/心动飘字 → 偶尔触发解锁。
奖励:被真实回应 + 数值微动 + 信息滴漏。钩子:"我这句他会怎么接?"

### ② 每次会话(5–15 分)
回到上次关系状态 → 推进一格(过阈值/挖到线索/解锁去处)→ 抵达小高潮(揭示/关系档跳级/戳心的话)→ 带钩子离开。
奖励:关系或剧情往前走了一步。钩子:离场悬念。

### ③ 跨天循环(天/周)
陌生→朋友→暧昧→恋人(或兄弟/敌对);故事一幕幕推;真相层层拼;走向为你定制的高潮。然后换角色/线 replay。
奖励:看一段关系长成、一个真相拼全。

## 关系 = 主货币(核心规则)
- **两轴**(已实现):好感(closeness)=信任亲近;心动(romance)=恋爱线。独立。
- **关系即钥匙**:每份内容(秘密层/地点/反应/表白/抉择/结局)挂在 (好感 或 心动) 阈值 + 可选"问到/做到"。
- **看得见**:关系档 + 心动条 + 解锁进度(X/Y);过阈值有 🔓 + 角色态度肉眼可见地变。
- **有代价**:冒犯/背叛掉好感、甚至滑向敌对档 — 经营才有重量。

## 四种体验各挂在哪(同一循环里分层)
| 体验 | 挂载点 |
|---|---|
| 陪伴(1) | 每句循环的底色,低阈值、永远可玩 |
| 悬疑(3) | 秘密碎片 = 好感+问到 阈值;给聊天一个"套真相"的目的 |
| 恋爱(2) | 心动轴 + 暧昧→恋人档;心动阈值解锁撩拨/表白/(18+)亲密 |
| 抉择(4) | 关键节点显式选择 + 幕推进 + 多结局 |

## "无硬结局,但有高潮"
- **结局 = 里程碑,不是终点**:达成有隆重演出+纪念,但世界继续、可往更高层走(milestone-ending 机制已支持)。
- **高潮 = 阈值被跨过的那一刻**:第一次卸防、心动到表白、真相最后一块拼上、围城抉择 — 用转场/特殊演出标记成"大解锁"。
- 只有"死亡/彻底破裂"是真终点(锁档),其余可继续。
