基本信息

🗺 地点

世界的物理地图。角色按作息待在地点里，玩家走过去才遇得到；地点上可以放「可搜查物证」。不配地图 = 所有角色随时在场（旧行为）。

角色

主角（is_lead）是默认开口的人。每个角色可挂秘密、作息表、随身物品、与他人的旧关系。卡库里的角色跨剧本复用（导入=复制，之后改卡不影响已导入的剧本）。
🪄 扔一大段文字，自动生成角色卡（小说片段/wiki/你自己的笔记都行）

幕 / 剧情事件

进入新一幕时引擎自动播该幕事件；幕可以锚定故事时间（第几天·什么时段），进幕时钟只进不退。

秘密 / 门控碎片

核心玩法：秘密分层碎片，按「好感/章节/追问/地点/事件」解锁。retrieval_key 是玩家追问时匹配的关键词（脱敏）。「谎言口径」是真相解锁前所有知情者统一说的假话，对峙成功会当场戳穿。

🖼 媒体（照片与背景）

给角色上传照片、给地点上传背景图（JPG/PNG/WebP，≤5MB），会替换 AI 生成的图。先保存草稿才有可上传的对象。

结局

结局是可达成的里程碑：默认在最后一幕按条件触发（真＞普通＞坏）。「机制触发」的结局（大限/危机/指认失败）不走条件匹配，只被对应机制点名。建议至少配一个好感≥0 的普通结局兜底。

⏳ 时钟与大限

时钟开着时，回合消耗时段（晨/午/夜），角色按作息挪动；配了大限，睡过截止日会直接触发对应结局。

⚠️ 危机压力表

一条从 0 涨到 100 的全局威胁（谁的注视/暴露风险）。到达各刻度播报警示旁白；爆表触发指定结局。不配 = 关闭。

📱 小手机

不在场的角色能捎信来（提醒赴约、爽约质问、恋人余温），玩家也能主动发消息。device 是叫法：手机 / 传呼机 / 口信 / 纸鹤……

🔍 指认结案

给玩家一次「我知道真相了」的下注时刻：有限次数里指认正确答案。答对置 flags.verdict_solved（真结局可 gate 在它上面）；次数用光触发失败结局。

🎲 命运骰

「做」有风险的动作时掷一枚 20 面骰定成败，结果强制写进剧情。

🏖 无尽沙盒

开启后这个剧本变成沙盒：玩家开局自定义世界观、开场人物按世界观现场生成、永不结束、玩家会死（死了只剩旁观）。时间与现实同步可单独关。

⚙️ 调参（tuning）

留空 = 用引擎默认值（占位符里显示默认）。全部旋钮说明见 docs/tuning.md。
