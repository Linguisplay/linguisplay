基本信息

角色

主角（is_lead）是默认开口的人。每个角色可以挂不同的秘密。

幕 / 剧情事件

进入新一幕时引擎会自动播该幕事件作为旁白，推动剧情。

秘密 / 门控碎片

核心玩法：秘密分层碎片，按「好感/章节/追问次数」解锁。retrieval_key 是给玩家追问时匹配的关键词（脱敏，别写剧透）。

结局

结局是可达成的里程碑，不是游戏结束——玩家在最后一幕按好感高低触发对应结局（取满足条件里最高级的：真＞普通＞坏），之后仍能留在世界里继续探索、甚至养更高好感解锁更好的结局。只有「死亡」是真正终结。死亡/坏结局也会在玩家做出致命举动时由 AI 当场触发。建议至少配一个「普通结局」兜底（好感≥0）。
