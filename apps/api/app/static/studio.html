📝 基本信息
更多设定（硬事实 / 关系总览 / 标签 / 18+ / 智能增强）
自动用这本的角色立绘排出盒绘（班底站中间），发布时会自动生成一次。 角色还没画脸时先出底版，等美术画好会自己重排。
👥 角色
主角（is_lead）是默认开口的人。写好「TA是谁 + TA想要什么」，其他都可以后补，或点卡里的「🪄 AI 补全空白」。
🪄 扔一大段文字，自动生成角色卡（小说片段/wiki/你自己的笔记都行）
🕸 关系网
上图下表：点两个头像直接建一对关系；点连线跳到对应行修改。 红线=仇、金线=厚，粗细=浓度。开局播种进活网，游戏中随剧情自动演变。
🎬 幕（章节）
幕 = 章节。每幕写一个「这幕要让玩家经历什么」；进新一幕时该幕事件自动上演。
🏁 结局
结局是可达成的里程碑：默认在最后一幕按条件触发（真＞普通＞坏）。建议至少配一个好感≥0 的普通结局兜底。
🗺 地点
世界的物理地图。角色按作息待在地点里，玩家走过去才遇得到；地点上可以放「可搜查物证」。不配地图 = 所有角色随时在场。
🔒 秘密（可解锁的真相）
核心玩法：秘密分层，玩家靠好感/追问/搜证一层层揭开。「谎言口径」是真相解锁前知情者统一说的假话，对峙成功会当场戳穿。
🖼 媒体（照片与背景）
给角色上传照片、给地点上传背景图（JPG/PNG/WebP，≤5MB），会替换 AI 生成的图。先保存草稿才有可上传的对象。
⏳ 时钟与大限
时钟开着时，回合消耗时段（晨/午/夜），角色按作息挪动；配了大限，睡过截止日会直接触发对应结局。
⚠️ 危机压力表
一条从 0 涨到 100 的全局威胁。到达各刻度播报警示旁白；爆表触发指定结局。不配 = 关闭。
📱 小手机
不在场的角色能捎信来，玩家也能主动发消息。device 是叫法：手机 / 传呼机 / 口信 / 纸鹤……
🔍 指认结案
给玩家一次「我知道真相了」的下注时刻：有限次数里指认正确答案；次数用光触发失败结局。
🎲 命运骰
「做」有风险的动作时掷一枚 20 面骰定成败，结果强制写进剧情。
🏖 无尽沙盒
开启后这个剧本变成沙盒：玩家开局自定义世界观、开场人物现场生成、永不结束。
💎 收费包
玩家用平台币「月石」购买的内容资格：门票 / 开局礼包 / 金手指位。确定性发货，创作者分成 70%。
⚙️ 调参
留空 = 用引擎默认值（占位符里显示默认）。全部旋钮说明见 docs/tuning.md。
